Agreed Incremental Build Order

  1. Phase 1: Backend Foundation & Persistence: Express server, MongoDB Mongoose schema, Multer upload (≤5MB, image/*), CRUD endpoints, contact projection guard, and separate reveal route.
  2. Phase 2: Explainable Matcher Engine & Seed Script: Pure scoring engine (100pt scale), Jest/Node unit tests validating PRD rules, /api/items/:id/matches endpoint, and 5-item seed script with real images.
  3. Phase 3: React Frontend (Manual-First Baseline): Feed page with filters, Report page with editable dropdowns, and Item Detail page with match cards and reveal button. Verified locally.
  4. Phase 4: Flask CV Microservice & Express Proxy: YOLOv8 inference, OpenCV HSV color extraction, Express /api/detect proxy with 3s timeout, and auto-tag UI hookup.
  5. Phase 5: Docker Compose & Ship Preparation: Root multi-container orchestration, end-to-end demo rehearsal, and repo polish.

Candidate Qualification: Opposite-type active item must satisfy (Same Category OR ≥2 Matching Factors) AND Score ≥ 25.

Factor Points Evaluation Rule & Chip Text
Same Category 40 pts item.category === candidate.category (excluding 'other')
Chip: "Same category"
Same Color 25 pts item.color === candidate.color (excluding 'other')
Chip: "Same color"
Description Keywords 8 or 15 pts Description words excluding stopwords, category, and color words.
1 shared word = 8 pts | 2+ shared words = 15 pts
Chip: "X shared keywords: word1, word2"
Location Overlap 10 pts Shared meaningful word in location (excluding digits, 'floor', 'desk', 'room', etc.)
Chip: "Same location area"
Close Date 10 pts Difference in item date ≤ 3 days
Chip: "Close date"
Qualitative Tiers: Strong match (≥70) | Good match (55–69) | Possible match (25–54).

YOLOv8 Class Mapping

  • backpack, handbag, suitcase → bag
  • cell phone → phone
  • bottle → bottle
  • umbrella → umbrella
  • laptop → laptop
  • book → book
  • All others / no detection → other

OpenCV HSV Color Classification

  • Black: Value < 45
  • White: Saturation < 35, Value > 190
  • Grey: Saturation < 40, 45 ≤ Value ≤ 190
  • Hues (Sat ≥ 40, Val ≥ 45): Red, Yellow, Green, Blue, Brown
  • Off-Palette Mapping: Orange → Red/Yellow; Purple/Pink → Red; Beige → White/Brown
  • Rule: Crop detection box (or 50% center crop fallback), per-pixel classification, majority vote.
Method & Endpoint Payload / Params Response & Behavior
POST /api/detect Multipart file image (in-memory, ≤5MB) Proxies in-memory to Flask (3s timeout); returns { category, color } without disk write.
GET /api/items ?type=&category=&status= Returns item array; contact is strictly excluded.
POST /api/items Multipart image + form fields Validates image (≤5MB), saves to ./uploads, creates MongoDB document.
GET /api/items/:id None Returns single item details; contact is strictly excluded.
GET /api/items/:id/matches None Computes heuristic score on opposite active items; returns top 3 meeting PRD rule & score ≥25.
POST /api/items/:id/reveal-contact None Returns { contact: item.contact }.
PATCH /api/items/:id/return None Updates status: 'returned', removing item from active matching.
